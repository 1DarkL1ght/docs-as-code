# ИИ-помощник интернет-магазина

Сервис автоматически отвечает на вопросы пользователей
или перенаправляет вопрос оператору.

Основные пользователи:
- пользователь;
- оператор поддержки.

Основные функции:
- автоматическая генерация ответа на обращение пользователя;
- определение категории обращения;
- перенаправление обращения оператору в случаях невозможности чат-бота ответить.

## Комплект документации
1. Описание проекта. Для команды разработки, для формирования понимания общей задачи.
2. Требования. Для команды разработки, в целях определения требуемого функционала.
3. Архитектура системы. Для команды разработки, в целях закрепления общего вида ПО.
4. Документация API. Для разработчиков веб-сайта, для простой и удобной интеграции чат бота.
5. Документация ML-модели. Для команды разработки, для удобного внедрения модели от команды ML-разработчкиков.
