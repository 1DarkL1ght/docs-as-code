# API

API предоставляет доступ к функциям ИИ-помощника интернет-магазина:
принимает вопросы посетителей, возвращает ответы чат-бота и передаёт
обращения оператору поддержки.

## Основные операции

- `POST /messages` — отправить сообщение чат-боту и получить ответ;
- `GET /messages/{messageId}` — получить результат обработки сообщения;
- `POST /operator-requests` — передать обращение оператору поддержки.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
