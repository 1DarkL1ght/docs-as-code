## Использование в проекте

Qwen3.8-27B используется как генеративная модель ИИ-помощника интернет-магазина. Backend передаёт ей текст вопроса из `POST /messages` и историю диалога, а полученный ответ сохраняет и возвращает в поле `ChatResult.answer`. Если модель не может дать надёжный ответ, обращение переводится в статус `operator_required` и может быть передано оператору через `POST /operator-requests`.

## Входные данные

Текст вопроса пользователя, предыдущие сообщения диалога и системная инструкция.

## Выходные данные

Сгенерированный текст ответа. В API он возвращается в поле `answer`.

## Ограничения

- **Потенциальное ограничение для нашего проекта:** карточка не документирует качество модели на русском языке и на терминологии конкретного интернет-магазина, поэтому это необходимо проверить на собственной выборке.
- **Потенциальное ограничение для нашего проекта:** режим рассуждений включён по умолчанию и может увеличить время ответа; для требования "быстрее 10 секунд" нужен режим без рассуждений или ограничение `reasoning_effort`.
- **Потенциальное ограничение для нашего проекта:** языковая модель может сгенерировать правдоподобный, но неверный ответ; ответы нужно ограничивать базой знаний и передавать оператору при низкой уверенности.

## Не рекомендуется использовать

- Для медицинских, юридических и финансовых решений без проверки специалистом.
- Для обработки платёжных данных и других чувствительных персональных данных.
- Как единственный источник информации о правилах магазина: ответы должны опираться на проверенную базу знаний.
